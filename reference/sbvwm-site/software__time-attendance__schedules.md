# Schedules | SBV Workforce Management

**Source:** https://www.sbvwm.com/software/time-attendance/schedules/

---

* Multiple schedules can be defined within a pay date
  * Start and end times, break and lunch rules, pay type and pay rules used for calculation can be changed on an individual schedule to handle daily exceptions
  * Alternate schedules provide a closest matching scenario based on the punches

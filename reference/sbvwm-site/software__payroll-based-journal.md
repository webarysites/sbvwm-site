# Payroll Based Journal | SBV Workforce Management

**Source:** https://www.sbvwm.com/software/payroll-based-journal/

---

The Payroll Based Journal module creates the XML file as required by CMS for electronic submission of your direct care hours to PBJ.

  * Allocates hours to the correct PBJ Job Type Code by department or by employee
  * Classifies each employees as either contract, exempt and non-exempt staff
  * Specify the pay types that should be submitted to PBJ while excluding unworked or non direct care hours
  * Create an XML file that can contain data from one day to 3 months
  * Allocates both punched and owed hours to the correct date including time owed for night shifts
  * Handles punches and hours that pass through midnight
  * Available Excel report that shows a detailed breakdown of each employee’s PBJ hours per day

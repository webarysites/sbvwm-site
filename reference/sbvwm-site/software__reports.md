# Reports | SBV Workforce Management

**Source:** https://www.sbvwm.com/software/reports/

---

* Over 250 reports created in PDF or Excel format
  * Fast object based reporting engine handles hierarchical display of data
  * All standard reports: employee, time card, punch, hours, scheduling, staffing, accruals, attendance
  * Custom reporting supported with pivot grid report designer
  * Excel template based reports allow you to separate report design from report data
  * Export of raw data for your own analysis or importing

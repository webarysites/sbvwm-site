# Software | SBV Workforce Management

**Source:** https://www.sbvwm.com/software/

---

SBV provides scalable workforce management solutions for single to multi-facility clients with 100 to 10,000 employees. The available workforce management modules include **Time and Attendance** , **Scheduling** , **Accruals** , **Payroll Based Journal** , **License Tracking** , **Health Tracking** and **In Service management**.

### Overview

  * Flexible deployment options; in-house on your existing IT infrastructure, deploy on your hosted or cloud infrastructure, or have SBV deploy in the cloud
  * Flexible clients; Web, Windows, Terminal Services, or Citrix
  * Server software runs on Microsoft Windows Server 2008 or newer
  * Supports Microsoft SQL Server 2008 or newer
  * Highly optimized database design
  * Full support for the HandPunch biometric time clocks
